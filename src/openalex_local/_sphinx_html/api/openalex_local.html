openalex_local API

The public API is generated automatically from the package’s __all__. Each object is documented exactly once here via automodule (autodoc + napoleon); do not add per-object autoclass/autofunction directives for the same names below, or Sphinx will raise duplicate object description warnings (which fail the docs build under -W).

OpenAlex Local - Local OpenAlex database with 284M+ works and semantic search.

Example

>>> from openalex_local import search, get
>>> results = search("machine learning neural networks")
>>> work = get("W2741809807")  # OpenAlex ID
>>> work = get("10.1038/nature12373")  # or DOI
openalex_local.search(query, limit=20, offset=0)[source]

Full-text search across works.

Uses the corpus full-text index over titles and abstracts.

Parameters:

  • query (str) – Search query (web-search syntax: bare words, “quoted phrases”, or, leading - to exclude)

  • limit (int) – Maximum results to return

  • offset (int) – Skip first N results (for pagination)

Return type:

SearchResult

Returns:

SearchResult with matching works

Example

>>> from openalex_local import search
>>> results = search("machine learning")
>>> print(f"Found {results.total} matches")

openalex_local.update(dsn=None, since=None, dry_run=False, snapshot_dir=None)[source]

Incrementally update the local OpenAlex corpus.

Downloads only the S3 snapshot directories newer than the recorded last_sync_date (or since when given) and upserts them into the corpus.

Parameters:

  • dsn (str, optional) – PostgreSQL connection string override. Defaults to the corpus scitex_dev.store.host_store resolves for this host, which SCITEX_STORE_DSN moves.

  • since (str, optional) – Override start date (YYYY-MM-DD). Defaults to the recorded last_sync_date.

  • dry_run (bool) – Preview only — list what would be downloaded without writing.

  • snapshot_dir (str, optional) – Snapshot works directory. Defaults to <repo>/data/snapshot/works.

Returns:

Statistics from differential_update: dates_processed, records_upserted, elapsed_seconds (and dry_run when applicable).

Return type:

dict

openalex_local.enrich(results, include_abstract=True, include_concepts=True)[source]

Enrich search results with full metadata.

This function re-fetches works from the database to ensure all fields are populated, including abstract and concepts which may be truncated in search results.

Parameters:

  • results (SearchResult) – SearchResult from a search query

  • include_abstract (bool) – Include full abstract text (default True)

  • include_concepts (bool) – Include concept/topic data (default True)

Return type:

SearchResult

Returns:

SearchResult with enriched Work objects

Example

>>> results = search("machine learning", limit=10)
>>> enriched = enrich(results)
>>> for work in enriched:
...     print(work.abstract)  # Full abstract available

openalex_local.configure(dsn)[source]

Configure for direct corpus access at an explicit address.

Only needed to reach a corpus OTHER than the one this host resolves to. Leave it alone and scitex_dev.store.host_store decides, which is what SCITEX_STORE_DSN is for.

Parameters:

dsn (str) – PostgreSQL connection string for the corpus

Return type:

None

Example

>>> configure("postgresql://reader@scitex-primary:55432/scitex")
